# Web research (2026-11-24): GPUI idioms, pitfalls, docs/skill structure
Idioms: App owns entities; Entity = id+refcount; update leases state; notify/emit queue effects flushed after outermost update; observe vs subscribe (EventEmitter). Render called per frame for dirty views; RenderOnce components; .when/.when_some; keep SharedString in state. size_full needs sized parent. uniform_list measures item 0, needs bounded height + overflow hidden y, else not lazy; store scroll handle. Actions: on_action fires only on focused dispatch path -> track_focus + focus(window) + key_context. Async: single foreground thread; spawn gives WeakEntity+AsyncApp; dropping Task cancels -> store/detach; weak calls fallible. Testing: TestAppContext, VisualTestContext, simulate_keystrokes, run_until_parked; use executor timers only.
Pitfalls: re-entrant update panic (defer); missing notify; dropped Subscription/Task; outer cx in closure; strong cycles leak (use weak back-refs); missing element .id() for click/hover/scroll, unstable/duplicate ids; uniform_list unbounded height; size_full collapse; actions not firing (focus/context); blocking foreground; reading unset global (try_global); swallowing errors.
Docs: Diataxis (tutorial=getting started counter, how-to guides, reference=pkg.go.dev, explanation=concepts). Skill: name lowercase-hyphen <=64, description 3rd person what+when <=1024, body <500 lines, refs one level deep with TOC >100 lines, checklists + validate loops, evals. Go README: pkg.go.dev badge, install, minimal example, guides links, platform reqs; Example funcs in _test.go.
Sources: zed.dev/blog/gpui-ownership, docs.rs/gpui, gpui-ce AGENTS.md, matinaniss.github.io/gpui-book, diataxis.fr, platform.claude.com agent-skills best practices, pkg.go.dev/about.
