# M0-element handoff

element.rs, view.rs, taffy.rs and inspector.rs are in element.go, view.go, taffy.go and inspector.go. api-contracts.md §1 lists the new stubs by owner and §3.2 records the shapes.

- M0-window-core: replace the `ElementID` placeholder (`ElementIDView`, `ElementIDName`, `ElementIDNamedInteger`, `NewElementID`, `Hash`, `String`, `GoString`; keep these names and signatures, add the other variants). `Hash` must stay rustc's derived enum hash (discriminant with `WriteUsize`, then the fields): `extendPathHash` folds it into `GlobalElementID`. Port `elementIDStack` (`push` = append `extendPathHash(last hash, id)` to `hashes`, `globalID()` = `globalElementIDWithHash(ids, last hash or emptyPathHash)`). Keep the `Window` fields `nextFrame *frame`, `elementIDStack`, `dirtyViews map[EntityID]struct{}`, `windowProfiler`, `a11y windowA11y` and the `frame` fields `focus Option[FocusID]`, `dispatchTree *dispatchTree` (element.go reads them); `newWindow` must set `a11y` from `newWindowA11y(...)` so `viewTypeNames` is a live map (view.go writes it in debug builds). `prepaintStateIndex` / `paintIndex` replace upstream's `PrepaintStateIndex` / `PaintIndex` (comparable). `deferArenaDrop(f)` queues f for `ArenaClearNeeded.Clear` (D-ARENA): `ViewElement` uses it to release a view handle that was never rendered.
- M0-window-paint: `ScaleFactor`, `TextStyle`, `WithID[R](ElementID, f)` (concrete `ElementID`; callers convert with `NewElementID`), `ContentMask`, `prepaintIndex`, `reusePrepaint(start, end)`, `paintIndex`, `reusePaint(start, end)`, `elementOpacity`. `WithElementState` must look states up by `GlobalElementID.Hash` plus `Equal` (the type is not comparable).
- M0-window-dispatch: `ComputeLayout`, `LayoutBounds`, `SetViewID`, `CurrentView`, `withRenderedView[R]`, `IsInspectorPicking`, `inspectorEnabled`, `buildInspectorElementID` (key `nextInspectorInstanceIds` on `InspectorElementPath.Hash` plus `Equal`). The layout engine is `*TaffyLayoutEngine` from `NewTaffyLayoutEngine()`; `RequestMeasuredLayout` on Window wraps `(*TaffyLayoutEngine).RequestMeasuredLayout`.
- M0-window-a11y: `windowA11y` is upstream's `A11y` (renamed: `a11y` is the imported package), `a11yNodeBuilder` is `A11yNodeBuilder`; keep `isActive`, `nodeBounds`, `viewTypeNames`, `nodes.push(id, node) bool`, `nodes.pop()`, `nodes.recordNodeInfo`, `nodeDebugInfo` / `nodeCreator` (fields `synthetic`, `view Option[string]`, `elementID Option[string]`, `sourceLocation *SourceLocation`), `newA11ySubtreeBuilder(parentID, *a11yNodeBuilder)` and `(A11ySubtreeBuilder).withCreator(nodeCreator) A11ySubtreeBuilder`; the `A11ySubtreeBuilder` stub fields `parentID`, `nodes`, `creator` are placeholders.
- M0-div-paint: port `frame_cost` (element.rs:941, `#[ignore]` -> t.Skip "prints timings; run by hand") as `TestElementGlobalElementIDTests_FrameCost` in element_test.go and set its row in core-window.md (it is `blocked:M0-div-paint`).
- Everyone: `Entity[T].IntoAnyElement()` moves the handle into the element (upstream's `.child(entity.clone())` is `.Child(entity.Clone())`). `Inspector.select` is `selectElement`.
