# M4-windows-events handoffs

- M4-windows-window: stubs.go declares `WindowsWindowState`, `WindowsWindowInner`, `Callbacks`, `ClickState`, `WindowBorderOffset`, `A11yState` and `a11yCell` with the fields events.go reads; move them into window.go (add the remaining window.rs fields), port `ClickState.update/systemUpdate`, `WindowBorderOffset.update`, `WindowsWindowState.isFullscreen/isMaximized`, `WindowsWindowInner.visibility`, and delete those stubs. Upstream `system_settings()` is the field `systemSettings` (no method). The window procedure calls `inner.handleMsg(handle, msg, wparam, lparam)`. Callbacks follow upstream's take/restore: a field is nil while its callback runs. `DrawCoordinator` / `NewDrawCoordinator` live in events.go. `a11yCell.borrowed` models the RefCell borrow flag.
- M4-windows-shell: port `DirectManipulationHandler` (setScaleFactor, onPointerHitTest, update, drainEvents) and delete its stub.
- M4-windows-a11y: fill `A11yState.updateWindowFocusState`, `A11yState.handleWMGetObject` (return the LRESULT conversion as a closure, called after the borrow is released) and `raiseA11yEvents`.
- M4-windows-platform: `handleKeydownMsg` is called from the message loop (upstream platform.rs); keyboard layout/mapper are `NewWindowsKeyboardLayout`, `WindowsKeyboardLayoutUnknown`, `NewWindowsKeyboardMapper`; `currentModifiers` / `currentCapslock` / `generateKeyChar` are package-level. The WM_GPUI_* constants now live in events.go.
