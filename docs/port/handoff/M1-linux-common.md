# Handoff: M1-linux-common

- M1-wayland-client / M1-x11-client: implement `common.LinuxClient` (display_connection.rs forwarding set; `Close` is the drop). The loop API is `common.EventLoop` / `LoopHandle` (`InsertSource`, `InsertEventSource`, `InsertIdle`, `InsertTimer[After]`, `Remove`), `LoopSignal`, `NewGeneric` for the display fd and `LifecycleEventSource` (BeforeSleep / BeforeHandleEvents) for Wayland's prepare_read. `CompositorGPUHintFromDevT` returns `(vendor, device, ok)`; build `wgpu.CompositorGPUHint` from it.
- M1-linux-platform: the platform.rs section's Go target now names `internal/common/common.go`; the three display-mode test rows are still `todo` and target `platform/linux/platform_test.go`; move them to a section with that target when porting them. `OpenURIInternal`, `RevealPathInternal` and `InhibitIdleSleep` take the bus as `func() (*godbus.Conn, error)`: pass `common.SessionBus`. `prevent_idle_sleep` composes `InhibitIdleSleep` + a oneshot + `AwaitIdleSleepPrevention`. `on_power_mode_change` uses `common.SystemBus` with `dbus.MonitorPowerMode` and `common.PowerSender.Clone()`.
- Exit stage (lint owner): `LinuxDispatcher.SpawnRealtime` needs `runtime.LockOSThread` + `unix.SchedSetAttr(SCHED_FIFO, 65)` to match upstream, which `paritycheck -lint` forbids outside package platform. Allow it in platform/linux/internal/common/dispatcher.go and restore it, then drop D-LINUX-RTPRIO.
- Root window stage (window.go, not ported yet): `HeadlessWindow` releases its connection's window lease only in `PlatformWindow.Close` (upstream's drop of the boxed window), so the window-removal path must call `Close` on the platform window, or `HeadlessConnection.HasWindows` stays true and display-mode switching is refused.
- `LinuxCommon.Close` / `LinuxDispatcher.Close` exist for tests and shutdown; runnables dispatched after `Close` are dropped.
