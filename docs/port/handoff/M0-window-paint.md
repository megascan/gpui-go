# M0-window-paint handoff

window.rs 2562-5700 is in window_paint.go, including the private items without parity rows (`markViewDirty`, `refreshVisibility`, `debugState`, `dispatchKeystrokeObservers` / `dispatchKeystrokeInterceptors(keystroke *Keystroke, pref, [action Action (nil = None),] contextStack, cx)`, `windowDisplayChanged`, `notifyDisplayObservers`, `appearanceChanged`, `buttonLayoutChanged`, `underline`, `snapBounds`, `snapStroke`, `snapBorderWidths`, `coverBounds`, `snappedContentMask`, `recordEntitiesAccessed`, `invalidateEntities`, `present`, `presentIfNeeded`, `drawRoots`, `prepaintTooltip`, `prepaintDeferredDraws`, `paintDeferredDraws`, `deferredDrawTraversalOrder`, `withElementOpacity`, `windowLargestBorderInterior`, `insertQuad`, `shouldUseSubpixelRendering`, `paintAnimatedSvg(..., animation Option[spriteAnimation], ...)`). `last_window_bounds()` / `display_id()` are not methods: they clash with the fields `lastWindowBounds` / `displayID`, which callers read directly.

API shape choices:
- Every `with_*` helper is one generic method with a single `R` (`WithID`, `WithGlobalID`, `WithRemSize`, `WithTextStyle`, `WithContentMask`, `WithElementOffset`, `WithAbsoluteElementOffset`, `withElementOpacity`, `WithElementNamespace`, `WithTabGroup`, `PaintLayer`, `WithElementState`, `WithOptionalElementState`); void callers return `struct{}`. Option parameters are `Option[T]` (`WithRemSize(Option[Pixels])`, `WithTextStyle(Option[TextStyleRefinement])`, `WithContentMask(Option[ContentMask[Pixels]])`, `WithTabGroup(Option[int])`). `ElementID` parameters take `ElementID`, not `impl Into` (use `NewElementID`).
- `Transact[T](f func(*Window) (T, error)) (T, error)` (D-OPT). `Root[V]() (Option[Entity[V]], bool)`: bool = has a root, Option = downcast; the entity is a clone the caller releases. `Focused`, `FocusLostRestoreTarget` return handles the caller releases. `UseKeyedState` / `UseState` return a clone the caller releases (the stored one stays in element state).
- `SetCursorStyle(style, hitbox Hitbox)`, `PaintUnderline` / `UnderlineBounds` / `PaintUnderlineWithExclusions` take `UnderlineStyle` by value, `PaintStrikethrough` takes `StrikethroughStyle`; `PaintPath(path, color Background)`; `PaintSvg(bounds, path, data []byte (nil = None), transformation, color, cx) error`; `PaintImage(..., data *RenderImage, ...)`; `PaintSurface(bounds, imageBuffer uintptr)` is compiled on every OS like `PaintSurface` in scene.go; `SetExclusiveEdge`, `SetTrafficLightPosition`, `SetNativeTitlebarVisibility` and the `feat:profiler` methods are compiled always (the platform trait has them unconditionally). `UseAsset[A, S, O]` / `GetAsset[A, S, O]` mirror `App.FetchAsset`.
- `ObserveRelease[T](entity, cx, func(*T, *Window, *App))`, `Observe[T](entity, cx, func(Entity[T], *Window, *App))`, `Subscribe[T, E](entity, cx, func(Entity[T], *E, *Window, *App))`; the entity handed to callbacks is released when the callback returns.

New stubs in stubs.go (final signatures, panicking unless noted):
- M0-window-dispatch: `focusNodeIDInRenderedFrame(Option[FocusID]) dispatchNodeID`, `applyTextInputConfiguration(cx)`, `resetCursorStyle(cx)`, `prepaintInspector(width, cx) Option[AnyElement]`, `paintInspector(Option[AnyElement], cx)`, `paintInspectorHitbox(cx)`, `takeElementState(*GlobalElementID, reflect.Type) (elementStateKey, elementStateBox, bool)`, `insertElementState(key, box)`, free `observeKeyedState[S](Entity[S], EntityID, cx)`; `RenderablePromptHandle` gained `view promptViewHandle` (`anyView() AnyView`, returns a new handle). Until these land `Draw`, `Focus`, `Blur` (via the existing `clearPendingKeystrokes` stub), `WithElementState` and `DispatchAction` panic.
- `WithElementState` stores `*Option[S]` in `elementStateBox.inner` (upstream's `Box<Option<S>>`, taken out during the callback to detect re-entrancy) and `typeName` from `typeNameOf`.
- M0-window-a11y: placeholder bodies, faithful while there are no native views / a11y is inactive: `syncNativeViewFocus` (drops dead weak pointers, returns when none are left, panics otherwise), `endCompositionBeforeFocusingNativeView` (returns when there are no native views), `windowA11y.syncActiveFlag` (no-op, a11y stays inactive), `windowA11y.setWindowTitle` (stores `windowTitle`). Panicking: `windowA11y.beginFrame`, `endFrame(frameDebugInfo) a11y.TreeUpdate`; type `frameDebugInfo{viewportSize, scaleFactor, tabStopCount}` (upstream `a11y::debug::FrameDebugInfo`).
- M0-elements-media: `SmoothSvgScaleFactor = 2` (final value), `SvgRenderer.renderAlphaMask(params, bytes []byte) (Size[DevicePixels], []byte, bool, error)` (bool false = upstream `Ok(None)`).
- M3-profiler-hang: `DebugFrameOverlayMode` (`Next` panics) and no-op `DebugFrameOverlay.mode/setMode/resetStats/recordFrame/paint`.

For M0-window-tests: none of the window.rs tests are ported here. `paritycheck -lint` currently fails on files outside this stage (platform_testing_platform.go:285, internal/linux/wl/display.go:285, internal/linux/xcbshim/setup.go:5, platform/macos/system_notifications.go:111).

For M0-exit (window.go has no builder owner left):
- Frame clearing drops owned handles without releasing them: `frame.clear` / `elementStateMap.clear`, the overwrite in `elementStateMap.insert`, and `Transact`'s truncation of `tooltipRequests` / `deferredDraws`. Upstream's drops release them, so `UseKeyedState` entities that are no longer rendered stay alive until the GC safety net (release observers fire late; strict leak detection reports them). Shape of the fix: give `elementStateBox` a release path (type-assert `inner` to an interface with `Release`, or store a release func next to it) called on clear, overwrite and truncation; release `tooltipRequest.tooltip.View` the same way.
- M0-window-core's debt item about closing the a11y channel senders "whoever ports remove_window" is not this stage's: upstream `remove_window` only sets `removed`; the senders go when app.rs drops the removed Window, i.e. app.go's window-removal path.
