# M4-ios-app handoff

- Exit stage (verify.sh / STAGES.md): `GOOS=ios GOARCH=arm64 CGO_ENABLED=0 go vet` cannot run with go1.27.4 ("ios/arm64 requires external (cgo) linking"), and purego v0.11.3 refuses `ios` without cgo (`_PUREGO_REQUIRES_CGO_ON_IOS` in is_ios.go). verify.sh:432 and :436 fail as written. Working substitute used here: a throwaway go.work outside the repo (`use <worktree>` + `replace github.com/ebitengine/purego v0.11.3 => <copy without is_ios.go>`) and `GOWORK=<it> GOOS=darwin GOARCH=arm64 CGO_ENABLED=0 go vet -tags ios ./internal/apple/... ./platform/ios/... ./platform`; it passes. Real iOS builds need CGO_ENABLED=1 with the iOS SDK on the macOS runner.
- Exit stage (paritycheck lint owner): `paritycheck -lint` requires every platform/ios file to build only for `ios`, but STAGES.md M4-ios-app puts pure-logic files under `//go:build darwin` so their tests run on darwin CI. Flagged files: application.go, application_test.go, callback_slot.go, events.go, events_test.go, gpui_ios_impl.go. Allow `darwin` for platform/ios in lint.go.
- M4-ios-window: `stubs.go` (ios) holds `IosWindow`, `newIosWindow(handle, options, *iosPlatformState) (*IosWindow, error)` and `(*IosWindow).register()`; replace them in window.go and delete stubs.go. `register` calls `platform.application.registerWindow(w.state)`, drop/close calls `unregisterWindow`. The window registry stores the `applicationWindow` interface (application.go): the window state must implement `notifyVisibilityChange(gpui.WindowVisibility)`, `notifyActiveStatusChange(bool)`, `attachToScene(uikit.UIWindowScene)`, `requestFrame()`, compared by pointer identity. `callbackSlot[T]` (callback_slot.go, darwin) has `set`, `take`, `with` and `callbackSlotWithR` for callbacks returning values. `set_status_bar_style` reaches the platform through `currentApplication()`.
