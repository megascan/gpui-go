# gpui-go

Go port of Zed's GPUI at zed@6501df15765d66d6c2a2b66b1eb22434ccef3f86. Target: full functional and logical parity.

## Stack
- Module `github.com/megascan/gpui-go`, Go 1.27 (go line 1.27.3, forced by xo/okage). Apache-2.0 (LICENSE, NOTICE).
- Deps (pinned, never add/upgrade, never `go get`/`go mod tidy`/`go install`): purego v0.11.3, oliverbestmann/webgpu v1.38.1 (wgpu-native v29), go-text/typesetting v0.3.5, xo/okage v0.20.1, jezek/xgb v1.3.1, jezek/xgbutil, godbus/dbus/v5 v5.2.4, x/image v0.48.0, x/sys v0.50.0, gen2brain/avif v0.6.0. `internal/deps` (`//go:build deps`) blank-imports them.
- Linux: Wayland via libwayland-client + purego (wlgen wrappers), X11 via xgb; render/wgpu (cgo, `linux || js`); text/gotext. macOS/iOS: objc via purego + Metal. Windows: COM + D3D11 + DirectWrite. Web: js/wasm, WebGPU with WebGL2 fallback.

## Rules (short form of STAGES.md Shared decisions)
- Port, don't redesign: upstream names, order of operations, constants, panic messages. Only DESIGN 5.1-5.7 re-expressions. One upstream file -> one Go file (listed exceptions only).
- References read-only: `_ref/<crate>/`, `~/.cargo/registry/src/index.crates.io-1949cf8c6b5b557f/<crate>-<ver>/`, `_ext/taffy`.
- Edit only your stage's owned paths. Root package `gpui`: one writer at a time; forward refs in `stubs.go` (`panic("gpui: unimplemented <symbol>")`). Bugs elsewhere: repro in own paths + `docs/port/handoff/<stage>.md`.
- Only M0-bootstrap and exit/CI stages edit AGENT.md, TECH_DEBT.md, docs/port/PARITY.md, docs/port/OWNER-CHECKS.md, ci.yml. Others write `docs/port/{debt,handoff,owner-checks}/<stage>.md`, and `docs/port/status/<stage>.done` on completion.
- Parity rows: `todo|done|dev:<id>|n/a:<id>|blocked:<stage>`; edit row by row with the code; new ids in the area file's `## Deviations registered here`. `go run ./internal/cmd/paritycheck -area <a> ...` must pass.
- API shape: generic methods on concrete types, free generic funcs over sealed AppContext; `R` suffix for value-returning closures; `(T, error)`; `(T, bool)` / `gpui.Option[T]`; iter.Seq; enums `type X uint8`; TypeId -> reflect.Type. Elements: `Element[RL, PP]`, self-typed mixins, no `any`.
- Drop (D-RAII): explicit Release/Close/... where upstream drops; GC never stops subscriptions or tasks. Async (D-ASYNC): iter.Pull coroutines on the scheduler; block only in gpui/scheduler primitives.
- JSON: encoding/json/v2; schemas via internal/jsonschema. Actions register in `init`.
- Tests: one Go test per upstream test (N14 names), same package; `#[gpui::test]` -> `gpui.RunTest`; strict leak detection. Never open windows or touch session bus, a11y bus, keyring, notifications, clipboard or user services; display tests only with GPUI_TEST_DISPLAY=1.
- Generated: `*_gen.go`, `// Code generated by <tool>; DO NOT EDIT.`, `//go:generate go run github.com/megascan/gpui-go/internal/cmd/<tool>`; committed; `go generate ./...` byte-identical.
- Build: root imports no platform/renderer/cgo/purego (`paritycheck -lint`). cgo only render/wgpu and internal/cmd/wlspike. internal/{linux,apple,win} by OS constraint. Cross `CGO_ENABLED=0 go vet` + `go test -c -o /dev/null` for darwin, windows, js/wasm. `runtime.LockOSThread()` only in package platform `init`.
- Style: gofmt; no comments except terse godoc on exported API, `//go:`/`//gpui:` directives, generated headers; no licence headers; wrap errors with `%w`; no init side effects beyond registration.
- Docs live in lowercase `docs/`; never create `DOCS/`.
- Verify: `sh docs/port/verify.sh <stage>`; never edit verify.sh or STAGES.md (exit stages may, together). Slow commands in background, `nice`; build outputs to /dev/null.
- Screenshots only via internal/cmd/shoot into docs/port/screenshots/<group>/<example>.png; open and check every image. Unverifiable-here items -> `docs/port/owner-checks/<stage>.md` as `YOU: ...`.
- Git: branch feat/port (base dev); only exit/CI stages commit and push, only paths of stages with a `.done` file; never `git add -A`, force-push or Co-Authored-By. Apple/iOS paths first committed by M4-ci-macos, Windows by M4-ci-windows.
- Known limits: L-GLYPH, L-JPEG, L-SVGTEXT, L-WGPUVER, L-WEBTHREADS (cite as `dev:L-x` / `n/a:L-x`).

## State after M0-exit
- Headless core complete: root package, scheduler, sumtree, collections, gpuiutil, refineable, a11y, internal/{taffy,lyon,etagere,jsonschema}. M0 parity rows are done / dev / n/a or `blocked:<M3 stage>` (profiler journal/hang, bench context, root capture, inspector reflection).
- `stubs.go` holds only profiler-hang, journal, debug-overlay and visual-test symbols; M3-root-capture deletes it.
- Window teardown: `Window.drop` (window_paint.go) releases root, prompt, both frames (element states via `dropElementState`, tooltip requests, input handlers, tab stops), the platform input handler and the a11y channels; app.go calls it on window removal and `Shutdown`, test teardown via `releaseAppWindows`. Tests need no manual root/drag release helpers.
- `SetTooltip` takes ownership of the tooltip view (callers pass a clone). Element state types that own handles implement `dropElementState()`.
- Test teardown order: release contexts, `DrainTasks`, then leak report (testing.go).
- CI: draft PR feat/port -> dev; Actions blocked by account billing (TECH_DEBT CI-BILLING). Owner checks in docs/port/OWNER-CHECKS.md.
